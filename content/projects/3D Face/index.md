This is a 3D face reconstruction pipeline using Python to recover facial geometry from a single 2D image using both BFM and FLAME morphable models.
Implemented using an energy-based optimization framework incorporating sparse landmark alignment, dense photometric consistency, and regularization terms to refine shape and expression parameters.
